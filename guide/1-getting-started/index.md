# Getting started

- [Install](install.md) - Desktop installers for macOS, Windows and Linux, and how Sunstone keeps itself up to date.
- [Open a folder](open-a-folder.md) - Launch Sunstone on any directory of markdown from the command line or the launcher.
- [Run in the browser](run-in-browser.md) - Use Sunstone without installing it with `npx sunstone-md`, or serve the editor with `sunstone serve`.
