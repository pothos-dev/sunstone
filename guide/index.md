# Sunstone User Guide

Sunstone is a markdown editor for git users. Point it at any folder of `.md` files and you get live preview, wikilinks, backlinks, full-text search and git review, with your files staying plain markdown on disk. It has first-class support for the [Open Knowledge Format](/6-okf/okf-support.md).

This guide is itself a Sunstone Bundle, served read-only by [Sunstone Web](/5-web/sunstone-web.md). Everything you see here (the Explorer, search, backlinks, the outline) is the product showing itself.

- [Getting started](1-getting-started/) - Install Sunstone, open a folder, or run it in the browser without installing anything.
