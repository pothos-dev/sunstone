# Customizing

On the desktop, change them on the [settings page](settings.md). Everything is stored in one `config.json`: `~/.config/sunstone/config.json` on the desktop (and under `sunstone serve`), or the file named by `SUNSTONE_CONFIG` on Sunstone Web. You can also edit the file by hand. The settings page only writes the settings you change on it, and Sunstone Web only reads the file.

- [Settings](settings.md) - The settings page: theme, colours, fonts, how a Bundle first opens, and keyboard shortcuts.
- [Theme colours](theme-colors.md) - Override the base colours of the light and dark schemes.
- [Fonts](fonts.md) - Choose the fonts and sizes for the interface, text, headings and code, optionally from font files.
