# Search

## Full-text search

Searches the text of every Concept in the Bundle and shows each match with a snippet. It's built in: no external tools needed.

## Quick nav

A fuzzy palette that jumps to any Concept by name. It searches tags too, so you can drill down from a tag to the Concepts that carry it.

## Tags

The Tags browser lists every tag in the Bundle with the number of Concepts that use it. Nested tags expand as a tree.

All three also work in [Sunstone Web](/web/sunstone-web.md).
