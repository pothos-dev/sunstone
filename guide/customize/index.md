# Customizing

Both settings live in one `config.json`: `~/.config/sunstone/config.json` on the desktop (and under `sunstone serve`), or the file named by `SUNSTONE_CONFIG` on Sunstone Web. Sunstone reads it and never writes it.

- [Theme colours](theme-colors.md) - Override the base colours of the light and dark schemes.
- [Fonts](fonts.md) - Choose the fonts and sizes for the interface, text, headings and code, optionally from font files.
