# Tiling workspace

Split the editor into columns and tiles to see several Concepts side by side. Dividers can be dragged, each tile closes on its own, and **Alt+arrow keys** move between tiles.

Each tile has a slim header with clickable breadcrumbs and the Concept's path. The layout is remembered across restarts.
