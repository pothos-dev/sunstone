# Sunstone Web

- [Sunstone Web](sunstone-web.md) - Serve a Bundle in any browser from a Docker image: read-only for visitors, the full editor for signed-in users.
- [Git-synced wiki](git-synced-wiki.md) - Back a Sunstone Web deployment with a git remote so browser edits and pushes reconcile on their own.
- [Reading API](reading-api.md) - Fetch any page as Markdown or JSON, list a folder, or search, from scripts and agents.
